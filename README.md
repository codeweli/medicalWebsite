# CareSync Healthcare Information Management Website

A responsive healthcare patient information management dashboard built with HTML, CSS, and JavaScript.

## Features

- Patient record management dashboard
- Add, edit, delete, and search patient records
- Status filtering and completion progress tracking
- Clinical overview cards for appointments and alerts
- Local data persistence using browser localStorage

## Run locally

Open the project in a browser directly, or run a small local server:

```bash
cd c:/Users/John Eymard/medicalWebsite
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` – page structure
- `styles.css` – healthcare dashboard styling
- `script.js` – patient management logic and local storage
